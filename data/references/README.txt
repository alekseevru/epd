Положите сюда counteragents.csv, выгруженный из ЛК Диадок.

Остальные справочники приложение обновляет автоматически из TMS:
- companies.xlsx — Контрагенты;
- vehicles.xlsx — Автомашины;
- drivers.xlsx — Водители;
- route-points.xlsx — Географические объекты / точки маршрута.


Договоры:
- contracts.json — пополняемый справочник договоров клиентов.
- Если файла contracts.json нет, используется встроенный справочник приложения.
- Формат даты: ГГГГ-ММ-ДД. Пример находится в contracts.example.json.
