# Развёртывание «Создание ЭПД» на сервере

Файлы `docker-compose.yml` и `Dockerfile` запускаются из корня проекта.

1. При необходимости скопируйте `.env.server.example` в `.env`. Логин и пароль TMS можно задать там для всех сотрудников либо оставить пустыми — тогда пользователь введёт их на первом экране.
2. Создайте каталог `data/references` и положите туда только `counteragents.csv` из Диадока. Остальные справочники приложение получает из TMS по кнопке «Обновить реестры из TMS».
3. Запустите:

   `docker compose -f docker-compose.yml up -d --build`

4. Проверка состояния:

   `docker compose -f docker-compose.yml ps`

По умолчанию сайт доступен на порту `3000`. Для корпоративного адреса и HTTPS разработчик может поставить перед контейнером Nginx, Traefik или существующий reverse proxy.

Пароль TMS не входит в образ и не хранится в репозитории. Кэш реестров хранится в Docker volume `agr-work`.
